# Data Analytics Portfolio

Портфолио аналитика данных. Проекты по SQL, Python, Power BI, статистике.

## О себе

- 10 месяцев коммерческого опыта в роли аналитика
- Работаю с API, автоматизацией выгрузок, отчётностью
- Изучаю: SQL (PostgreSQL), Python, Power BI, статистику и A/B-тесты
- Цель: перейти в продуктовую аналитику

## Навыки

- **SQL:** JOIN, GROUP BY, CTE, оконные функции, подзапросы
- **Python:** pandas, базовые скрипты, обработка данных
- **Excel:** сводные таблицы, ВПР, СЧЁТЕСЛИМН
- **BI:** Power BI (в процессе)
- **Статистика:** в процессе изучения

## Структура репозитория

- `01-sql/` — задачи и проекты по SQL
